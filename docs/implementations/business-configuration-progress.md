## Test-first loop evidence

1. Verified the existing 147-test baseline, then created the feature branch before any source/test edits.
2. Added profile/general/AI/knowledge, rule and policy tests first. The initial run failed on missing configuration models and selectors.
3. Implemented versioned persistence, validation and consumers. Tests exposed missing endpoint paths, reporting inheritance and comparison settings; those were implemented and rerun.
4. Added integration, secret-reference, source approval, and reprocessing tests before their APIs. Implemented the missing slices, corrected a test-helper name collision, and added shared freshness history. All 28 initial feature tests passed.
5. Added edge tests; four failures exposed unredacted legacy secrets, row-per-connection lookups, a runtime confidence floor gap and disabled ingestion types being approvable. Fixed each implementation and reran the tests.
6. Added assertions for real retry scope enforcement and target-versus-time-trend separation. Both failed before implementation; the existing processing/monitoring owners now enforce the settings.
7. Added acceptance-command tests before the command existed, then implemented a reproducible demo through real API views. It validates 21 outcomes and detects corrupted current settings.
8. Added PostgreSQL tests for first-write serialization, version conflicts, queued-request idempotency and concurrent configuration/runtime progress. Added 0003-to-0004 upgrade preservation.
9. Added draft activation, pinned source/document versions, explicit archived retrieval, per-workflow AI narrowing, expired-policy archiving and effective API scope/platform-limit regressions. Fixed failures and reran the complete suite.
