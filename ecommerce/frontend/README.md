# Aurelo Storefront

Next.js 16 App Router, React 19, TypeScript, and Tailwind 4 storefront for Aurelo.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```

## Quality Gates

Run all quality checks before committing:

- Unit tests: `npm test`
- Type check: `npm run typecheck`
- Lint: `npm run lint`
- Format check: `npm run format:check`
- Production build: `npm run build`
