## 1. Context
Tokens exist (SF-02). `Price` needs money formatting, which SF-05 creates; so in this card `Price` receives an already formatted string (`formatted`, `compareAtFormatted`). Every component is a small typed function component with `className` merged through `cn`.

## 2. Required behaviour
1. `frontend/src/lib/cn.ts`: `export function cn(...inputs: ClassValue[]) { return twMerge(clsx(inputs)); }` (`clsx`, `tailwind-merge`).
2. `frontend/src/components/ui/Button.tsx`: `Button` forwards all `button` props (`React.ComponentProps<'button'>`, default `type="button"`) plus `variant?: 'primary' | 'secondary' | 'ghost' | 'link'` (default primary), `size?: 'sm' | 'md' | 'lg'` (default md), `loading?: boolean`, `asChild?: boolean` (uses `Slot` from `radix-ui` → `import { Slot } from 'radix-ui'` then `<Slot.Root>`; print the radix-ui export with `grep -n "Slot" node_modules/radix-ui/dist/index.d.mts` first and use what is there). Classes: base `inline-flex items-center justify-center gap-2 rounded-pill font-medium transition-[transform,background-color,color] duration-200 ease-out active:scale-[0.98] disabled:cursor-not-allowed disabled:opacity-50 min-h-11`; primary `bg-accent text-accent-fg hover:opacity-90`; secondary `border border-border-strong text-fg hover:bg-surface-2`; ghost `text-fg hover:bg-surface-2`; link `text-accent underline-offset-4 hover:underline min-h-0`; sizes sm `px-4 text-small`, md `px-5 text-body`, lg `px-7 text-body-lg min-h-13`. `loading` → renders `Spinner` before children, sets `aria-busy="true"` and `disabled`. Note `active:scale-[0.98]` is a unitless arbitrary value and allowed.
3. `IconButton.tsx`: like Button, requires `aria-label` (TypeScript: `'aria-label': string` required), square `size-11 rounded-pill`, variant ghost by default.
4. `Spinner.tsx`: `<span role="status" aria-label="Loading" className="inline-block size-4 animate-spin rounded-pill border-2 border-current border-t-transparent motion-reduce:animate-none" />`. When used inside a Button the Button passes `aria-hidden` instead of `role="status"` (prop `decorative?: boolean`).
5. `Input.tsx`: forwards `input` props; classes `h-12 w-full rounded-sm border border-border-strong bg-surface px-4 text-body text-fg placeholder:text-fg-muted aria-[invalid=true]:border-danger`. `Field.tsx`: props `{ id: string; label: string; hint?: string; error?: string; children: (aria: { id: string; 'aria-describedby'?: string; 'aria-invalid'?: true }) => React.ReactNode; optional?: boolean }`; renders `<label htmlFor={id}>` (`text-small font-medium`, appends " (optional)" when `optional`), the child via render prop, hint `<p id={id+'-hint'} className="text-small text-fg-muted">`, error `<p id={id+'-error'} className="text-small text-danger">` ; `aria-describedby` lists hint and error ids that exist.
6. `Select.tsx`: native `<select>` with the Input classes plus `appearance-none pr-10` and a `ChevronDown` icon (lucide, `aria-hidden`) absolutely positioned right.
7. `Checkbox.tsx`: wraps Radix `Checkbox` (`import { Checkbox as RadixCheckbox } from 'radix-ui'`) with a visible `label`; props `{ id, label, checked, onCheckedChange, disabled? }`; box `size-5 rounded-sm border border-border-strong data-[state=checked]:bg-accent data-[state=checked]:border-accent`, `Check` icon in `text-accent-fg`.
8. `RadioCard.tsx`: for use inside Radix `RadioGroup`; props `{ value, title, description?, aside?: React.ReactNode, disabled? }`; a full-width bordered card (`rounded-md border border-border p-4 data-[state=checked]:border-accent data-[state=checked]:bg-surface-2`), indicator dot. The item gets `aria-labelledby={titleId}` and `aria-describedby={descId}` (ids from `useId()`), so its accessible name is the title only (e.g. "Card payment").
9. `Badge.tsx`: `variant: 'neutral' | 'accent' | 'success' | 'warning' | 'danger'`; `text-label-caps rounded-pill px-2.5 py-1`; neutral `bg-surface-2 text-fg`, accent `bg-accent text-accent-fg`, success `bg-surface text-success border border-success`, warning `bg-surface text-warning border border-warning`, danger `bg-surface text-danger border border-danger` (the `bg-surface` keeps them readable over photos).
10. `Skeleton.tsx`: `<div aria-hidden="true" className={cn('rounded-sm bg-surface-2 motion-safe:animate-pulse', className)} />`.
11. `Price.tsx`: props `{ formatted: string; compareAtFormatted?: string | null; size?: 'sm' | 'md' | 'lg'; className? }`. Without compare-at: `<span className="tabular-nums">{formatted}</span>`. With compare-at: a wrapper `<span>` containing `<span className="sr-only">Sale price {formatted}, was {compareAtFormatted}</span>`, then `<span aria-hidden="true" className="text-accent">{formatted}</span> <s aria-hidden="true" className="text-fg-muted">{compareAtFormatted}</s>` (no `aria-label` on a plain span: axe forbids it). Sizes: sm `text-small`, md `text-body`, lg `text-title`.
12. `VisuallyHidden.tsx`: `<span className="sr-only">`. `Container.tsx`: `<div className={cn('mx-auto w-full max-w-360 px-5 md:px-8 xl:px-12', className)}>` (max-w-360 = 90 rem on Tailwind's 0.25 rem scale), prop `as?: 'div' | 'section' | 'header' | 'footer' | 'main'`.
13. `frontend/src/components/ui/index.ts` re-exports all of the above by name.
