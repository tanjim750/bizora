## 2. Required behaviour
1. `frontend/src/stores/announce-store.ts`: `useAnnounceStore = create<{ message: string; nonce: number; announce: (m: string) => void }>()` — `announce` sets the message and increments `nonce` (so the same text twice is announced twice). 2. `frontend/src/components/providers/Announcer.tsx` (`'use client'`): `<div aria-live="polite" aria-atomic="true" className="sr-only" data-testid="announcer">` showing the message; uses `nonce` as React `key` on an inner `<span>`.
3. `frontend/src/stores/ui-store.ts`: `useUiStore` with `searchOpen`, `mobileNavOpen`, `setSearchOpen(b)`, `setMobileNavOpen(b)`.
4. `frontend/src/stores/cart-store.ts` (`'use client'` NOT needed; plain module): `useCartStore = create<CartState>()` where `CartState = { cart: Cart | null; status: 'idle' | 'loading' | 'ready' | 'error'; error: string | null; pendingLineIds: string[]; drawerOpen: boolean; hydrate(): Promise<void>; addItem(input: { variantId: string; quantity: number; name: string }): Promise<{ ok: true } | { ok: false; error: ApiError | Error }>; updateQuantity(lineId: string, quantity: number): Promise<void>; removeLine(lineId: string): Promise<void>; openDrawer(): void; closeDrawer(): void; reset(): void }`. Behaviour (all API calls through `browserApi.cart`):
   - `hydrate`: status `loading` (keep the old cart), then `ready` with the cart; on error `error` status and `error = toUserMessage(e)`.
   - `addItem`: NOT optimistic; calls `browserApi.cart.addItem({ variantId: input.variantId, quantity: input.quantity })` (`name` is only for the announcement); on success set the cart, announce `Added ${name} to cart`, return `{ ok: true }`; on failure return `{ ok: false, error }` (the caller shows the message) and do not change the cart.
   - `updateQuantity`: optimistic: copy the previous cart, set that line's `quantity` (and nothing else) immediately, add the id to `pendingLineIds`; call the API; on success replace with the server cart and announce `Cart updated`; on `ApiError` `INSUFFICIENT_STOCK` call `updateQuantity(lineId, details.available)` once if `available > 0` else `removeLine(lineId)`, and announce `toUserMessage(e)`; on `LINE_NOT_FOUND` re-`hydrate()` and announce "Your cart was updated."; on any other error restore the previous cart and announce `toUserMessage(e)`. Always remove the id from `pendingLineIds`.
   - `removeLine`: optimistic: remove the line from a copy (recompute nothing else; the server response brings totals), announce `Removed ${productName}` after success; on error restore and announce the message.
   - `reset()`: cart `null`, status `idle`, drawer closed.
5. `frontend/src/stores/session-store.ts`: `useSessionStore = create<SessionState>()` with `user: Customer | null; status: 'unknown' | 'guest' | 'signed-in'; hydrate(); signIn(input): Promise<Customer>; register(input): Promise<Customer>; signOut(): Promise<void>`. `hydrate`: `browserApi.auth.me()` → signed-in; `ApiError` 401 → guest; any other error → guest (and `console.error` only when `process.env.NODE_ENV === 'development'`). `signIn`/`register`: call the API (errors propagate to the caller), set user + `signed-in`, then `await useCartStore.getState().hydrate()` (merged cart), announce "Signed in" (register: "Account created"). `signOut`: API, then user null + `guest`, `useCartStore.getState().reset()` and `hydrate()`, announce "Signed out".
6. `frontend/src/components/providers/CartHydrator.tsx` and `SessionHydrator.tsx` (`'use client'`): `useEffect(() => { void useXStore.getState().hydrate(); }, [])`, render `null`.
7. Edit `Providers.tsx`: inside MotionConfig render `{children}`, then `<CartHydrator />`, `<SessionHydrator />`, `<Announcer />`.
