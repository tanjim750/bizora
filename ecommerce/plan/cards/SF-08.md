## 2. Required behaviour
1. `frontend/src/mocks/server/cart.ts`:
   - `buildCart(mockCart | null)` → contract `Cart` (§4.11): lines resolved from current products (`productSlug`, `productName`, `variantTitle`, first product image, `unitPrice` = variant price, `compareAtUnitPrice`, `lineTotal`, `maxQuantity` = min(`availableQuantity`, `store.maxQuantityPerLine`), `stockStatus`), `itemCount`, `subtotal`, `freeShippingRemaining`, `updatedAt`. Null → the empty cart object.
   - `resolveCart(req)`: the cart of the signed-in customer (session cookie → customerId → the cart with that `customerId`), else the cart whose id is in the cart cookie, else null.
   - `getCart(req)` → 200 Cart. `addItem(req)`: body `{ variantId: string, quantity: int 1..maxQuantityPerLine }` (zod; 400 with fields); unknown variant → 404 `VARIANT_NOT_FOUND`; `availableQuantity === 0` → 409 `OUT_OF_STOCK` with `details: { lines: [{ lineId: null, variantId, available: 0 }] }`; existing line quantity + new quantity > available (or > maxQuantityPerLine) → 409 `INSUFFICIENT_STOCK` with `details: { variantId, available: min(available, maxQuantityPerLine) }` and nothing changes; otherwise create the cart if needed (id `cart_` + 8 hex; customerId = session customer or null) and set the cart cookie (30 days) when a new cart was created for a guest; merge into the existing line or append a new line (id `line_` + 8 hex); 200 Cart.
   - `updateLine(req, lineId)`: body `{ quantity: int ≥ 1 }`; unknown line → 404 `LINE_NOT_FOUND`; > available → 409 `INSUFFICIENT_STOCK` (details as above); 200 Cart. `removeLine(req, lineId)`: 404 or 200 Cart.
2. `frontend/src/mocks/server/auth.ts`:
   - `register(req)`: zod body (§5.4 rules; email lower-cased); existing email → 409 `EMAIL_TAKEN` with `fields: { email: ['An account with this email already exists.'] }`; create user `cus_` + 3-digit sequence, `createdAt` now; create session token (`sess_` + 24 hex), merge guest cart (below); 201 `{ customer }` with the session cookie.
   - `signIn(req)`: zod body; rate limit per 03-API-CONTRACT §2 (store failure timestamps per lower-cased email in `db.signInFailures`; keep only the last 60 s; if 5 or more failures in the window → 429 `RATE_LIMITED`, header `retry-after: 60`, `details: { retryAfterSeconds: 60 }`); wrong email or password → 401 `INVALID_CREDENTIALS` ("Invalid email or password.") and record a failure; success → clear failures, session, merge, 200 `{ customer }`.
   - Merge rule (§2): if the request has a guest cart (cart cookie, `customerId` null): if the customer has a cart, add each guest line into it (same variant → add quantities, cap at maxQuantity), delete the guest cart; else set the guest cart's `customerId` to the customer. Response also clears the cart cookie.
   - `signOut(req)`: delete the session; 204 with both cookies cleared. `me(req)`: 200 `{ customer }` or 401 `UNAUTHENTICATED`. `toCustomer(user)` strips `password`.
3. `frontend/src/mocks/server/checkout.ts`:
   - `computeQuote(cart, shippingMethodId)` → `Quote` exactly per §4.14 (tax `Math.round` of (subtotal + shipping) × taxRateBps / 10000 — half-up for positive numbers).
   - `getQuote(req)`: no cart or no lines → 409 `CART_EMPTY`; unknown method → 422 `SHIPPING_METHOD_UNAVAILABLE`; 200 Quote.
   - `placeOrder(req)`: in this order: missing `idempotency-key` header → 400 `IDEMPOTENCY_KEY_REQUIRED`; if the key is known: same body hash (`JSON.stringify(body)`) → return the stored response unchanged; different → 409 `IDEMPOTENCY_CONFLICT`; zod `PlaceOrderBodySchema` → 400 with fields; `countryCode` not in store countries → 400 `fields['shippingAddress.countryCode']`; empty cart → 409 `CART_EMPTY`; unknown method → 422 `SHIPPING_METHOD_UNAVAILABLE`; payment method unknown or `enabled: false` → 422 `PAYMENT_METHOD_UNAVAILABLE`; any line with quantity > available → 409 `OUT_OF_STOCK` with `details.lines` listing each such line `{ lineId, variantId, available }`; `expectedTotal.amount !== quote.total.amount` → 409 `PRICE_CHANGED` with `details: { quote }`; else create the order (`number` `AUR-1` + 5-digit `nextOrderSeq` → `AUR-100200`, id `ord_0200`, status `placed`, paymentStatus `pending`, lines copied with `oline_<seq>_<n>` ids, totals from the quote, `shippingMethod.price` = quote shipping, `customerId` from the session or null, `confirmationToken` `tok_` + 24 hex), decrement stock and `recomputeStock`, delete the cart, store the response under the key, 201 `{ order, confirmationToken }` with the cart cookie cleared.
4. `frontend/src/mocks/server/orders.ts`: `listOrders(req)` (401 without session; the customer's orders newest first; `page`, `pageSize` 1–50 default 10; `OrderSummary` items with `itemCount` = Σ quantities and `previewImages` from the first 3 lines' images that are not null); `getOrder(req, number)`: owner session OR `query.token === confirmationToken`, else 404 `NOT_FOUND` ("Order not found."); response strips `customerId` and `confirmationToken`.
5. Add to the `router.ts` route table: `GET /cart`, `POST /cart/items`, `PATCH /cart/items/:lineId`, `DELETE /cart/items/:lineId`, `POST /auth/register`, `POST /auth/sign-in`, `POST /auth/sign-out`, `GET /auth/me`, `GET /checkout/quote`, `POST /checkout`, `GET /orders`, `GET /orders/:number`.
6. `frontend/src/app/api/store/[...path]/route.ts` (Next route handler): `export const dynamic = 'force-dynamic'`; one `handle(request: NextRequest, { params }: { params: Promise<{ path: string[] }> })` exported as `GET`, `POST`, `PATCH`, `DELETE`. Steps: if `process.env.API_BASE_URL` is set → 404 `NOT_FOUND` envelope (the rewrite should have taken the request; this is a safety net); build `MockRequest` (path `'/' + path.join('/')`, `query` from `request.nextUrl.searchParams` (repeated keys → arrays), headers lower-cased, cookies from `request.cookies.getAll()`, body: `await request.text()` → `undefined` when empty, else `JSON.parse` (invalid JSON → 400 `VALIDATION_FAILED` "Body is not valid JSON.")); wait `Number(process.env.MOCK_LATENCY_MS ?? 250)` ms; call `handleMockRequest`; return `new Response(status === 204 ? null : JSON.stringify(body), { status, headers })` appending every `setCookies` entry with `headers.append('set-cookie', …)`.
