## 2. Required behaviour
1. `frontend/src/components/search/SearchDialog.tsx` (`'use client'`): Radix Dialog controlled by `useUiStore` `searchOpen`. Global keyboard: `keydown` listener on `window` opens it for `(metaKey || ctrlKey) && key === 'k'` (preventDefault) and for `/` when `document.activeElement` is not an input, textarea, select or contenteditable.
2. Layout: overlay `fixed inset-0 bg-overlay pt-24 px-4`; content `mx-auto w-full max-w-2xl rounded-lg bg-surface shadow-float` with Motion enter (opacity 0→1, y −8→0, `duration.base`; reduced: opacity only). `Dialog.Title` visually hidden "Search".
3. Input: `<label className="sr-only" htmlFor="site-search">Search products</label>`, `input id="site-search" type="search" role="combobox" aria-expanded aria-controls="search-results" aria-autocomplete="list" aria-activedescendant={active option id or undefined} placeholder="Search mugs, linen, lamps…"`, `Search` icon left, `kbd` "Esc" right.
4. Fetching: debounce 200 ms; only when `q.trim().length >= 2`; ignore out-of-order responses (keep a request counter); `browserApi.catalog.suggest(q)`.
5. States (exact copy from 05-PAGES): idle → heading "Popular" + chip links "Mugs" (`/shop?q=mug`), "Linen" (`/shop?q=linen`), "Lamps" (`/shop?q=lamp`); loading → 3 `Skeleton` rows (`h-12`); results → `<ul id="search-results" role="listbox" aria-label="Suggestions">` with group labels "Products" and "Categories" (each group a `role="group"` with `aria-label`), options `role="option"` ids `search-opt-<n>` `aria-selected` for the active one: product option = image 40 × 50 + name + `formatMoney(price)`; category option = name; last row option "See all results for “<q>”" → `/shop?q=<encoded q>`; no results (both arrays empty) → "Nothing found for “<q>”. Try a shorter word."; error → "Search is unavailable right now.".
6. Keyboard in the input: ArrowDown/ArrowUp move the active option (wrapping), Enter navigates to the active option (`router.push`) or, with none active, to `/shop?q=<q>`; Escape closes (Radix). Choosing any option closes the dialog and clears `q`.
7. Mouse: options are `<button>`s inside the `li` (`li role="option"`, button `tabIndex={-1}`) that navigate on click.
8. Edit `frontend/src/app/(store)/layout.tsx`: render `<SearchDialog />` after the CartDrawer.
