## 2. Required behaviour
1. `frontend/src/app/(store)/shop/page.tsx` (Server Component): `export default async function ShopPage({ searchParams }: { searchParams: Promise<Record<string, string | string[] | undefined>> })`; `const query = parseCatalogQuery(await searchParams)`; `const [list, categories] = await Promise.all([serverApi.catalog.listProducts(toProductListQuery(query)), serverApi.catalog.listCategories()])`; `generateMetadata` returns `{ title: catalogTitle(query, categoryName) }`; renders `<CatalogView query={query} list={list} categories={categories} />`. An `ApiError` with code `VALIDATION_FAILED` (bad URL) → redirect to `/shop` (`redirect` from `next/navigation`); other errors bubble to `error.tsx`.
2. `frontend/src/app/(store)/shop/loading.tsx`: Container, `Skeleton` title (`h-12 w-72`), `Skeleton` line (`h-4 w-40`), grid of 8 `ProductCardSkeleton` in the catalog columns; `aria-busy="true"` + sr-only "Loading products…".
3. `frontend/src/components/catalog/CatalogView.tsx` (`'use client'`): props `{ query: CatalogQuery; list: ProductList; categories: Category[] }`. `const [isPending, startTransition] = useTransition()`; `navigate(next: CatalogQuery, opts?: { scrollToGrid?: boolean })` → `startTransition(() => router.replace(catalogHref(next), { scroll: false }))`, and for page changes scrolls the grid heading into view (`behavior: reduced ? 'auto' : 'smooth'`).
   - Header (`Container py-12`): `h1.font-display.text-display-lg` = `catalogTitle(query, categoryName)`; when `query.q`: `<p>“{q}” — {totalItems} results</p>`; when a category: its description `text-body-lg text-fg-muted`; result count `<p id="result-count">{totalItems} products</p>` and a separate `sr-only` `aria-live="polite"` region that receives the same text only after a change (not on first render).
   - Toolbar row: `< lg` Button secondary "Filters ({count})" (count via `countActiveFilters`; "Filters" when 0) opening `FilterSheet`; `SortSelect` right-aligned.
   - `ActiveFilters` (when any chip): chips from `activeFilterChips(query, minor => formatMoney({ amount: minor, currency: list.items[0]?.price.currency ?? 'BDT' }))` with the category chip label replaced by the category name; each chip a `button` `aria-label={`Remove filter ${label}`}` → `navigate(chip.next)`; plus Button link "Clear all" → `navigate({ q: query.q })` (keeps the search term).
   - Body: `lg:flex lg:gap-12`; the aside `lg:w-64 lg:shrink-0`, the results `lg:flex-1`. Aside (`hidden lg:block`) = `FilterPanel`. Results: `<div aria-busy={isPending} className={cn(isPending && 'opacity-60 transition-opacity')}>` with `ProductGrid products={list.items} animateLayout columns="catalog"` or the empty state, then `Pagination`.
   - Empty state (exact copy, 05-PAGES §3): without q: "No products match these filters." + Button "Clear all filters" → `navigate({})`; with q: "No results for “<q>”." + "Check the spelling or try a broader word." + link "Browse all products" → `/shop`.
4. `frontend/src/components/catalog/FilterPanel.tsx` (`'use client'`): props `{ query, facets: Facets, categories: Category[], onChange: (next: CatalogQuery) => void }`. Sections each with an `h2.text-label-caps` and a `fieldset`/`legend` (visually the h2 can be the legend):
   - "Category": radio inputs ("All" + one per category with `facets.categories` count "(5)"; categories absent from the facet show count 0 and are disabled unless currently selected) → `withFilter(query, { category })`.
   - "Price": Radix `Slider` (`import { Slider } from 'radix-ui'`) two thumbs, `min`/`max` = `facets.price` min/max amounts, `step={10000}` (৳100), value = `[query.minPrice ?? min, query.maxPrice ?? max]`, thumbs `aria-label` "Minimum price" / "Maximum price", local state while dragging, `onValueCommit` → `withFilter(query, { minPrice: v[0] === min ? undefined : v[0], maxPrice: v[1] === max ? undefined : v[1] })`; formatted min and max labels under it. Hidden when `facets.price` is null.
   - "Color": swatch checkboxes: `label` wrapping a visually hidden `input type="checkbox"` and a `size-11 rounded-pill border` swatch (inline `backgroundColor`) with a focus ring on `peer-focus-visible`; `aria-label={`${label} (${count})`}`; count 0 and not selected → disabled; toggle with `toggleValue`.
   - "Size": checkbox chips; section hidden when `facets.sizes` is empty.
   - "Availability": `Checkbox` "In stock only" → `inStock: true | undefined`.
5. `FilterSheet.tsx` (`'use client'`): Radix Dialog bottom sheet (`fixed inset-x-0 bottom-0 top-16 rounded-t-lg bg-surface overflow-y-auto`), Motion y `'100%'` → 0 `spring.snappy`; title "Filters"; contains `FilterPanel` (applies live); sticky footer Button "Show {totalItems} results" closes the sheet.
6. `SortSelect.tsx`: `Field`-style label "Sort by" + `Select` with `SORT_OPTIONS`; value `query.sort ?? 'featured'`; change → `withFilter`-like but keeping filters: `navigate({ ...query, sort: v === 'featured' ? undefined : v, page: undefined })`.
7. `Pagination.tsx`: props `{ page: number; totalPages: number; hrefFor: (page: number) => string }`; nothing when `totalPages <= 1`; `<nav aria-label="Pagination">` with `Link` "Previous" (omitted on page 1), page links (pages 1, last, current ±1, ellipsis `…` spans between gaps; at most 7 items), current has `aria-current="page"`, "Next" (omitted on last page). Plain links (crawlable); CatalogView passes `hrefFor = (p) => catalogHref(withPage(query, p))`.
8. `ActiveFilters.tsx`: renders the chips row described in step 3 (props `{ chips, onRemove, onClearAll }`).
