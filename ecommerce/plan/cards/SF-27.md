   - Guard: when cart status is `ready` and `cart.lines.length === 0` → `router.replace('/cart')`. While the cart is not ready → a skeleton of the form + summary.
   - State: `values` (`emptyCheckoutValues(store, sessionUser?.email ??    - Quote: on mount (cart ready, not empty) and whenever `shippingMethodId` or `cart.updatedAt` changes → `browserApi.checkout.quote(values.shippingMethodId)`; `CART_EMPTY` → `router.replace('/cart')`.
   - Layout `Container py-10 lg:grid lg:grid-cols-12 lg:gap-12`: form `lg:col-span-7`, summary `lg:col-span-5 lg:sticky lg:top-24 self-start`. Mobile (`lg:hidden`): summary collapsible at the top: button `aria-expanded` "Show order summary {total}" / "Hide order summary {total}"; while collapsed its panel content is NOT rendered (so jsdom sees only one OrderSummary by default). The desktop summary column is `hidden lg:block`.
   - Error summary (when submit found errors): `<div role="alert" tabIndex={-1} ref={summaryRef}>` titled "Please fix these fields:" with a `<ul>` of links `href="#field-<key>"` (in `CHECKOUT_FIELDS` order) whose text is the message; focus it after a failed submit.
   - `<form noValidate onSubmit>` with `<fieldset disabled={submitting}>`; sections with `h2`: "1. Contact" (Email, Phone; signed in → line "Signed in as {email}"; any status other than `signed-in` (guest or still unknown) → "Have an account? " + `Link` "Sign in" → `/account/sign-in?next=/checkout`), "2. Delivery address" (First name, Last name, Address, "Apartment, suite, etc." optional, City, Postal code, Country select from `store.countries`), "3. Delivery method" (`ShippingMethodPicker`), "4. Input ids `field-<key>`; autocomplete tokens per 05-PAGES §6; `validateField` on blur for touched fields.
   - Submit button (Button `size="lg" className="w-full"`): label `Place order — {formatMoney(quote.total)}`, or "Place order" while `quote` is null; while the quote loads: disabled + text "Calculating total…" under it; submitting: `loading` + label "Placing your order…".
   - Submit flow: `validateCheckout` → errors → show summary; else `browserApi.checkout.placeOrder(toPlaceOrderBody(result.body, quote.total), keys.current())`. Success → `useCartStore.getState().reset()` then `router.push(`/order-confirmation/${order.number}?token=${encodeURIComponent(confirmationToken)}`)`. Errors: `VALIDATION_FAILED` → `mapApiFieldErrors` + summary + `keys.renew()`; `PRICE_CHANGED` → `setQuote(details.quote)`, banner `price` "Prices changed since you started checkout. Please review the new total.", `keys.renew()`; `OUT_OF_STOCK` → banner `stock` "Some items are no longer available." with the product names of `details.lines` (looked up in the cart) and a `Link` "Edit cart" → `/cart`, `await cart.hydrate()`, `keys.renew()`; `CART_EMPTY` → `router.replace('/cart')`; `SHIPPING_METHOD_UNAVAILABLE` / `PAYMENT_METHOD_UNAVAILABLE` → field error on the picker, `keys.renew()`; `IDEMPOTENCY_CONFLICT` → `keys.renew()` + banner `error` with `toUserMessage`; `NETWORK_ERROR` → banner `network` "You seem to be offline. Your order was not placed. Try again." (key NOT renewed); others → banner `error` `toUserMessage(e)`. Banners: `role="alert"`, warning style `border border-warning text-warning rounded-md p-4` (danger style for `error`/`network`).
5. `ShippingMethodPicker.tsx`: Radix `RadioGroup` of `RadioCard`s (`aria-label="Delivery method"`): title = label, description, aside = "Free" when this method is the quote's method and `freeShippingApplied`, else `formatMoney(price)`.
6. `PaymentMethodPicker.tsx`: `RadioGroup` (`aria-label="Payment method"`) of `RadioCard`s; disabled methods `disabled` with their description ("Coming soon.").
7. `OrderSummary.tsx`: props `{ cart: Cart; quote: Quote | null; status; taxLabel: string; onRetry }`: lines (image 64 × 80 with a quantity badge, name, variant, line total), then rows "Subtotal", "Delivery" ("Free" when `freeShippingApplied`), `${taxLabel} (${taxRateBps / 100}%)` → "VAT (5%)", "Total" (`text-title`); quote loading → `Skeleton` bars instead of the numbers; error → "We couldn't calculate the total." + Button link "Try again".
