## 2. Required behaviour
1. `frontend/src/lib/api/transport-http.ts`: `createHttpTransport(baseUrl: string, options: { revalidate?: number } = {}): Transport`. Builds `baseUrl` (trailing `/` removed) + `path` + query string (`undefined` skipped, arrays as repeated keys, booleans as `'true'`/`'false'`, numbers as strings, keys in insertion order). `fetch` init: `method`, `headers` (`accept: application/json`, plus `content-type: application/json` only when `body !== undefined`, plus `req.headers`), `body: JSON.stringify(body)` when present, `credentials: 'include'`, `cache: 'no-store'` for non-GET, and `next: { revalidate }` only for GET when `options.revalidate` is set. Response: status 204 → `body: null`; otherwise `await res.text()` then `JSON.parse` (invalid/empty → `null`); `headers` = lower-cased object. A thrown fetch error → throw `new ApiError(0, 'NETWORK_ERROR', 'Network request failed')`.
2. `frontend/src/lib/api/transport-mock.ts`: first line `import 'server-only';`; `export const mockTransport: Transport` that calls `handleMockRequest({ ...req, headers: { ...lower-cased req.headers, ...(req.body !== undefined ? { 'content-type': 'application/json' } : {}) }, cookies: {} })` and returns `{ status, body, headers }`.
3. `frontend/src/lib/api/create-api.ts`: `createApi(transport: Transport)` returns exactly these methods (each parses success bodies with the named schema; on `status` outside 200–299 throws `ApiError` built from `ErrorEnvelopeSchema.safeParse(body)` (fallback code `UNKNOWN`, message `'Unexpected error response'`); if the success schema fails → `ApiError(502, 'CONTRACT_MISMATCH', <first issue path and message>)`):
   - `store.get()` → `StoreConfig` (GET `/store`)
   - `content.home()` → `HomeContent` (GET `/content/home`)
   - `newsletter.subscribe(email: string)` → `{ status: 'subscribed' }` (POST `/newsletter`)
   - `catalog.listCategories()` → `Category[]` (returns `.items`)
   - `catalog.listProducts(query: ProductListQuery = {})` → `ProductList` (GET `/products`, query keys exactly as 03-API-CONTRACT §5.2)
   - `catalog.getProduct(slug)` → `Product`; `catalog.getRelated(slug, limit = 4)` → `ProductSummary[]`; `catalog.suggest(q)` → `Suggest`
   - `cart.get()`, `cart.addItem({ variantId, quantity })`, `cart.updateLine(lineId, quantity)`, `cart.removeLine(lineId)` → `Cart`
   - `auth.register({ firstName, lastName, email, password })` → `Customer`; `auth.signIn({ email, password })` → `Customer`; `auth.signOut()` → `void` (expects 204); `auth.me()` → `Customer`
   - `checkout.quote(shippingMethodId)` → `Quote`; `checkout.placeOrder(body: PlaceOrderBody, idempotencyKey: string)` → `PlaceOrderResult` (header `Idempotency-Key`)
   - `orders.list({ page = 1, pageSize = 10 } = {})` → `OrderList`; `orders.get(number, token?: string)` → `Order` (query `token` only when given)
   Path parameters are encoded with `encodeURIComponent`. Export `type StoreApi = ReturnType<typeof createApi>`.
4. `frontend/src/lib/api/server.ts`: first line `import 'server-only';`; `export const serverApi = createApi(process.env.API_BASE_URL ? createHttpTransport(process.env.API_BASE_URL, { revalidate: 60 }) : mockTransport);` and `export const isMockMode = !process.env.API_BASE_URL;`.
5. `frontend/src/lib/api/browser.ts`: `export const browserApi = createApi(createHttpTransport('/api/store'));` (no `server-only`, no mock import).
6. `frontend/next.config.ts`: add `async rewrites()` exactly as 02-ARCHITECTURE §4.1 and `images: { remotePatterns: process.env.IMAGE_REMOTE_HOST ? [{ protocol: 'https', hostname: process.env.IMAGE_REMOTE_HOST }] : [] }`. Keep `reactStrictMode` and `poweredByHeader`.
