## 2. Required behaviour
`frontend/src/lib/catalog/query.ts` exports:
1. `type CatalogQuery = Omit<ProductListQuery, 'pageSize'>` and `const CATALOG_PAGE_SIZE = 24`.
2. `const SORT_OPTIONS = [{ value: 'featured', label: 'Featured' }, { value: 'newest', label: 'Newest' }, { value: 'price-asc', label: 'Price: low to high' }, { value: 'price-desc', label: 'Price: high to low' }, { value: 'name-asc', label: 'Name: A to Z' }] as const`.
3. `parseCatalogQuery(input: URLSearchParams | Record<string, string | string[] | undefined>): CatalogQuery` — tolerant: unknown keys ignored; invalid values dropped (never throws): `q` trimmed, empty → absent, max 100 chars (cut); `category` must match the slug regex; `collection` ∈ featured/new/sale; `color`/`size` arrays (dedupe, keep order, drop empty); `minPrice`/`maxPrice` non-negative integers (strings of digits only); if both and min > max → swap them; `inStock` present only when value is `'true'`; `sort` ∈ SORT_OPTIONS values, `'featured'` → absent (default); `page` integer ≥ 2 kept, otherwise absent.
4. `serializeCatalogQuery(q: CatalogQuery): string` — `URLSearchParams` text with keys in this fixed order: `q, category, collection, color, size, minPrice, maxPrice, inStock, sort, page`; arrays as repeated keys; defaults omitted (no `sort=featured`, no `page=1`); returns `''` when nothing is set. Round trip: `parseCatalogQuery(new URLSearchParams(serializeCatalogQuery(q)))` deep-equals `q` for any `q` produced by `parseCatalogQuery`.
5. `catalogHref(q: CatalogQuery): string` → `'/shop'` or `'/shop?' + serialized`.
6. `withFilter(q: CatalogQuery, patch: Partial<CatalogQuery>): CatalogQuery` — merges, removes keys whose value is `undefined`, `''` or `[]`, and always drops `page` (filters reset paging). `withPage(q, page)` sets page (page 1 → absent).
7. `toggleValue(list: string[] | undefined, value: string): string[]`.
8. `countActiveFilters(q): number` — counts `category`, `collection`, each `color`, each `size`, the price range as one (`minPrice` or `maxPrice`), `inStock`; NOT `q`, `sort`, `page`.
9. `activeFilterChips(q, format: (minor: number) => string): { key: string; label: string; next: CatalogQuery }[]` — in this order: `q` → label `“<q>”`; `category` → the slug (the page replaces it with the category name); `collection` → "Sale" / "New in" / "Most loved"; each color → the label; each size → the label; price → `"<min>–<max>"`, `"From <min>"` or `"Up to <max>"`; inStock → "In stock". `next` = the query without that chip (via `withFilter`).
10. `toProductListQuery(q): ProductListQuery` → `{ ...q, pageSize: CATALOG_PAGE_SIZE }`.
11. `catalogTitle(q, categoryName?: string): string` — "Search results" when `q`; else the category name when `category`; else "Sale" / "New in" / "Most loved" per collection; else "Shop all".
