Renders breadcrumb + `<ProductView product={product} store={store} />` inside `Container py-8 lg:py-12`.
   Breadcrumb: `<nav aria-label="Breadcrumb"><ol className="flex gap-2 text-small text-fg-muted">`: "Shop" → `/shop`, category name → `/shop?category=<slug>`, product name (`aria-current="page"`, not a link).

State `selection` initialised with `initialSelection(product, searchParams.get('variant'))`; on change, update the URL with `router.replace(`?variant=${variant.id}`, { scroll: false })` (only when a variant exists). Layout: `lg:grid lg:grid-cols-12 lg:gap-12`; gallery `lg:col-span-7`; info `lg:col-span-5 lg:sticky lg:top-24 self-start`. Info content: badges (as on ProductCard), `h1.font-display.text-display-md`, subtitle `text-body-lg text-fg-muted`, `Price size="lg"` of the selected variant (`formatMoney`), `VariantPicker`, `StockBadge`, a placeholder `<div data-add-to-cart-slot />` (SF-22 replaces it), delivery note "Free standard delivery over {formatMoney(threshold)}." (omitted when the threshold is null), `ProductDetails`.
3. `ProductGallery.tsx` (`'use client'`): props `{ images: Image[]; productName: string }`; state `index`. Desktop: main image `relative aspect-4/5 overflow-hidden rounded-lg bg-surface-2` (`data-gallery-main`, `next/image fill priority sizes="(min-width:1024px) 58vw, 100vw"`), cross-fade between images with `AnimatePresence mode="popLayout"` (opacity, `duration.fast`); a button over the main image `aria-label="Zoom image"` opening a Radix Dialog with the full image (`object-contain`, `Dialog.Title` sr-only `{productName} image {n} of {total}`, close button "Close zoom"); thumbnails row `mt-4 flex gap-3`: buttons `aria-label={`Show image ${n} of ${total}`}` `aria-pressed`, `size-20 rounded-md overflow-hidden`. Keyboard: the main image wrapper is focusable (`role="region"`, `tabIndex={0}`, `aria-label={`${productName} images`}`) and ArrowLeft/ArrowRight change the image. Mobile (`< lg`): a horizontal `snap-x snap-mandatory overflow-x-auto` strip of full-width images + dots (`aria-hidden`) + an sr-only live text "Image {n} of {total}" updated from scroll position (IntersectionObserver on each slide). Single image → no thumbnails, no dots.
4. `StockBadge.tsx`: props `{ status: StockStatus }`; wrapper `<div data-testid="stock-badge">` → `in_stock` Badge success "In stock"; `low_stock` warning "Low stock — order soon"; `out_of_stock` danger "Sold out".
5. `ProductDetails.tsx`: Radix `Accordion` (`type="multiple"`, `defaultValue={['description']}`) with items "Description" (paragraphs), "Details" (`<dl>` of `details` label/value), "Delivery & returns" (text: each shipping method `"{label}: {description}."` joined by a space, then "Unused items can be returned within 14 days."). Trigger buttons `text-body font-medium py-4 w-full flex justify-between` with a `ChevronDown` that rotates when open; content height animation via Radix CSS vars is NOT used (no height animation); content just appears.
6. `frontend/src/app/(store)/products/[slug]/loading.tsx`: gallery `Skeleton aspect-4/5 rounded-lg` + 5 text `Skeleton` lines; `aria-busy="true"`.
7. `frontend/src/app/(store)/products/[slug]/not-found.tsx`: `h1` "We couldn't find that product." + Button asChild "Browse the shop" → `/shop`.
