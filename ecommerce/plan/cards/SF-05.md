## 2. Required behaviour
1. `frontend/src/lib/api/schemas.ts` exports these schemas (names exact), all `z.object({...})` (zod strips unknown keys by default; keep that):
   `MoneySchema`, `ImageSchema`, `ShippingMethodSchema` (`id, label, description, price: Money, freeOverThreshold: boolean, estimatedDays: { min: int, max: int }`), `PaymentMethodSchema` (`id, label, description, enabled`), `StoreConfigSchema`, `CategorySchema`, `CategoryListSchema` (`{ items }`), `OptionValueSchema`, `ProductOptionSchema`, `StockStatusSchema` (`z.enum`), `VariantSchema`, `BadgeSchema` (`z.enum(['new','sale','bestseller'])`), `ProductSummarySchema`, `ProductSchema` (`ProductSummarySchema.extend({...})`), `FacetsSchema` (with `price` nullable), `paginated(item)` (function returning the §4.17 object schema), `ProductListSchema` (`paginated(ProductSummarySchema).extend({ facets: FacetsSchema })`), `RelatedProductsSchema` (`{ items: ProductSummary[] }`), `SuggestSchema`, `CartLineSchema`, `CartSchema` (`id: string | null`, `updatedAt: string | null`, `freeShippingRemaining: Money | null`), `CustomerSchema`, `CustomerEnvelopeSchema` (`{ customer }`), `AddressSchema` (with the §4.13 length/regex rules and `line2: z.string().max(120).nullable()`), `QuoteSchema`, `OrderLineSchema`, `OrderStatusSchema`, `PaymentStatusSchema`, `OrderSchema`, `OrderSummarySchema`, `OrderListSchema` (`paginated(OrderSummarySchema)`), `PlaceOrderBodySchema` (§5.5 body with the phone regex `^\+?[0-9 ()-]{7,20}$`, `note: z.string().max(500).nullable()`), `PlaceOrderResultSchema` (`{ order, confirmationToken }`), `HomeContentSchema` (`icon` as `z.enum(['truck','leaf','refresh','shield'])`), `NewsletterResultSchema` (`{ status: z.literal('subscribed') }`), `ErrorCodeSchema` (`z.enum` of every code in §3 including the client-only `NETWORK_ERROR`, `CONTRACT_MISMATCH`, `UNKNOWN`), `ErrorEnvelopeSchema` (`{ error: { code: z.string(), message: z.string(), fields: z.record(z.string(), z.array(z.string())).nullable(), details: z.record(z.string(), z.unknown()).nullable(), requestId: z.string() } }` — `code` is a plain string here so unknown codes still parse).
   Use `z.number().int()` for integers, `z.string().datetime()` is NOT used (accept any string for dates: `z.string().min(1)`), slugs `z.string().regex(/^[a-z0-9]+(?:-[a-z0-9]+)*$/)`, swatch `z.string().regex(/^#[0-9A-Fa-f]{6}$/).nullable()`, currency `z.string().regex(/^[A-Z]{3}$/)`.
2. `frontend/src/lib/api/types.ts`: `export type X = z.infer<typeof XSchema>` for every schema above (names without `Schema`, e.g. `Money`, `Product`, `Cart`, `Paginated<T>` as a generic interface `{ items: T[]; page: number; pageSize: number; totalItems: number; totalPages: number }`), plus:
   - `ProductListQuery = { q?: string; category?: string; collection?: 'featured' | 'new' | 'sale'; color?: string[]; size?: string[]; minPrice?: number; maxPrice?: number; inStock?: boolean; sort?: 'featured' | 'newest' | 'price-asc' | 'price-desc' | 'name-asc'; page?: number; pageSize?: number }`
   - `ApiRequest`, `ApiResponse`, `Transport` exactly as 02-ARCHITECTURE §4.
3. `frontend/src/lib/api/errors.ts`: `export type ErrorCode = z.infer<typeof ErrorCodeSchema>`; `export class ApiError extends Error { constructor(public status: number, public code: string, message: string, public fields: Record<string, string[]> | null = null, public details: Record<string, unknown> | null = null, public requestId: string | null = null) }` (set `this.name = 'ApiError'`); `isApiError(e: unknown): e is ApiError`; `toUserMessage(e: unknown): string` returning the exact "Frontend shows" text of 03-API-CONTRACT §3 per code (for `INSUFFICIENT_STOCK`: `Only ${details.available} left — we've updated the quantity.`; for `RATE_LIMITED`: `Too many attempts. Try again in ${details.retryAfterSeconds ?? 60} seconds.`; `UNAUTHENTICATED`: "Please sign in."; `NOT_FOUND`: "This item is no longer available."; `VALIDATION_FAILED`: "Please check the highlighted fields."; `OUT_OF_STOCK`: "Sorry, this is sold out."; `LINE_NOT_FOUND`: "Your cart was updated."; `EMAIL_TAKEN`: "An account with this email already exists."; any non-ApiError or unknown code → "Something went wrong. Please try again."). Export `const USER_MESSAGES` (the code → text map) so tests can compare.
4. `frontend/src/lib/format/money.ts`: `formatMoney(m: Money, locale = 'en-BD'): string` using `Intl.NumberFormat(locale, { style: 'currency', currency: m.currency, currencyDisplay: 'narrowSymbol', minimumFractionDigits: m.amount % 100 === 0 ? 0 : 2, maximumFractionDigits: m.amount % 100 === 0 ? 0 : 2 })` on `m.amount / 100`; `toMinor(major: number): number` = `Math.round(major * 100)`; `toMajor(minor: number): number` = `minor / 100`; `addMoney(a, b)` (same currency, throws otherwise); `multiplyMoney(m, n)`.
5. `frontend/src/lib/format/date.ts`: `formatDate(iso: string): string` → `Intl.DateTimeFormat('en-GB', { day: 'numeric', month: 'short', year: 'numeric', timeZone: 'Asia/Dhaka' })` ("26 Nov 2026"); `formatMonthYear(iso)` → `{ month: 'long', year: 'numeric' }` ("March 2026").

## 3. Tests (write first) — `frontend/tests/unit/sf-05-contract.test.ts`
- Every JSON example in 03-API-CONTRACT parses: copy the §4.3 StoreConfig, §4.8 ProductSummary, §4.11 Cart, §4.15 Order, §4.16 HomeContent and the §3 error envelope examples verbatim into the test as objects and `expect(() => XSchema.parse(obj)).not.toThrow()`.
- `MoneySchema.safeParse({ amount: 10.5, currency: 'BDT' }).success === false`; `{ amount: -1 }` fails; currency `'bdt'` fails.
- `ProductSummarySchema` strips an unknown key: parsing `{ ...example, secret: 1 }` returns an object without `secret`.
- `AddressSchema` rejects `postalCode: '!'` and `firstName: ''`.
- `PlaceOrderBodySchema` rejects `phone: 'abc'` and accepts `'+8801712345678'`.
- `formatMoney({ amount: 145000, currency: 'BDT' }) === '৳1,450'`; `formatMoney({ amount: 1234567, currency: 'BDT' }) === '৳12,345.67'`.
- `formatDate('2026-11-26T08:15:00Z') === '26 Nov 2026'`; `formatMonthYear('2026-03-14T10:00:00Z') === 'March 2026'`.
- `toUserMessage(new ApiError(409, 'INSUFFICIENT_STOCK', 'x', null, { available: 3 }))` → `"Only 3 left — we've updated the quantity."`; `toUserMessage(new Error('x'))` → `'Something went wrong. Please try again.'`; `isApiError(new ApiError(500,'INTERNAL','x')) === true`.
- `ErrorCodeSchema.options` includes `'PRICE_CHANGED'`, `'NETWORK_ERROR'`, `'CONTRACT_MISMATCH'`.
