## 2. Required behaviour
1. `frontend/src/lib/product/variants.ts` (pure):
   - `type Selection = Record<string, string>` (option name → value label).
   - `selectionOf(variant: Variant): Selection` = `{ ...variant.options }`.
   - `initialSelection(product: Product, variantId?: string | null): Selection` — the variant with `variantId` if it exists, else `defaultVariantId`.
   - `findVariant(product, selection): Variant | null` — the variant whose `options` equal the selection for every option name.
   - `isValueAvailable(product, selection, optionName, value): boolean` — true if the variant with `{ ...selection, [optionName]: value }` exists and has `availableQuantity > 0`.
   - `selectValue(product, selection, optionName, value): Selection` — sets the value; if that exact combination does not exist as a variant, picks the first variant (product order) that has this value, preferring available ones, and returns its selection.
   - `maxQuantity(variant: Variant, maxPerLine: number): number` = `Math.max(0, Math.min(variant.availableQuantity, maxPerLine))`.
2. `frontend/src/components/product/VariantPicker.tsx` (`'use client'`): props `{ product: Product; selection: Selection; onChange: (s: Selection) => void }`. Renders nothing when `product.options` is empty. For each option: a wrapper with a visible label written exactly as `<p className="text-small"><span className="text-fg-muted">{name}:</span> {selected value}</p>` and `<div role="radiogroup" aria-label={name}>`. Use Radix `RadioGroup` (`import { RadioGroup } from 'radix-ui'`) for roving focus: items are `RadioGroup.Item` with `value` = label and `aria-label` = label (+ ", sold out" when not available).
   - Color option (option name `"Color"`): round swatches `size-11 rounded-pill border border-border` with inline `backgroundColor` and an outer ring when checked (`data-[state=checked]:ring-2 data-[state=checked]:ring-fg ring-offset-2 ring-offset-bg`); unavailable → a diagonal line overlay (`after:` pseudo element rotated 45°, `bg-fg-muted`).
   - Other options: chips `min-h-11 rounded-pill border border-border-strong px-4 text-small data-[state=checked]:bg-fg data-[state=checked]:text-bg`; unavailable → `line-through text-fg-muted`.
   - `onValueChange(v)` → `onChange(selectValue(product, selection, name, v))`.
